# Move Accuracy & Provenance Guardrails

Load this reference when crafting high-stakes, legal, financial, security, or
code-review Moves where attribution, risk framing, or authorization boundaries
are sensitive.

## Provenance & Uncertainty

- Attribute source claims and distinguish them from verified facts.
- Keep unknown authors unknown, and distinguish a revision's author from the
  original author. Make attribution visible in supported copy if the byline is
  unverified.
- Preserve the seriousness of a reported risk without dropping its hedge.
- Distinguish a draft change from a demonstrated improvement.
- Verify reviewers' claims against the primary sources too; agreement is not a
  receipt.

## Scope & State Integrity

- Do not turn diverted attention into a formally paused project.
- Do not treat missing channel data as proof that an event or reply did not
  happen.
- Keep money, authority, irreversibility, and uncertainty visible before the
  user answers.
- Do not claim a proposed safeguard is implemented without evidence.
- Before shortening copy on a revision, inspect action bindings so a narrower
  label never hides broader execution. Never remap existing user answers to
  changed questions.
- For substantive copy revisions on sensitive Moves, have an independent critic
  compare drafts against sources and verify rendering on the intended surface.
